# CypherGPT

CypherGPT is an AI-powered rap battle game show platform that generates and analyzes rap battles using advanced language models. It features:

- Personalized diss profiles
- Tone and persona control (e.g., battle as Eminem, Tupac, or Shakespeare)
- Rhyme enforcement and fallback mechanisms
- Real-time scoring, flow analysis, and audience voting
- Interactive and gameified experience
